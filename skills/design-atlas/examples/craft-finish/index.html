TriplicateConditions

Conditions under which this page was made.

  1. One light. It hangs straight above the desk. Every sheet's shadow is the same tinted ink, layered at 1, 2, 4, 8, 16 and 32 px.
  2. Paper has corners. Nothing is rounded except the rubber stamp and the buttons, by 2 px.
  3. Two inks. Carbon blue to write with, red to number and to stamp. Three paper stocks: white, pink, yellow.
  4. Printed and typed. What the printer set is in Franklin. What someone typed in is in a typewriter face, so a column adds up by eye.
  5. What moves. Scrolling pulls each copy out from under the sheet above it. Old impressions on the blotter drift more slowly than the paper. The stamp lands on a short spring. Ask for reduced motion and all of it stays still.
  6. The lamp. Light and dark are one value per colour. The carbon sheet is dark by one attribute, with no second set of tokens.

Set in Libre Franklin and IBM Plex Mono. Every value above is a token in templates/tokens-starter.css; this page only sets the expression layer.
